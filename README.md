# telegram-bot

Мост «Bee»: пересылает сигналы из канала-источника (челлендж Arki 200-2000$) по таргетам:
TG #1 (русский перевод), TG #2 Heaven, аккаунты (Telethon), Discord webhook Bee,
selfbot-каналы Discord, webhook Rebel Angels; в конце — одна сводка админам.

## Как идёт пост
- **Текст** фильтрует `block_reason` (стоп-фразы, реклама, копитрейдинг…).
- **Картинка** проверяется так же, как у бота 5k-50k (`image_filter.py`, OCR RapidOCR,
  без внешних API). Режим — переменная `IMAGE_FILTER`:
  - `strict` (по умолчанию) — дальше уходят только карточки сделок/ордеров и балансы;
    реклама, профили копитрейдинга, бренды бирж, скрины Telegram/X/Discord, промокоды,
    QR, ссылки — блок; прочие картинки — админу на проверку;
  - `ads` — блокируется только реклама и чужие скрины, остальные картинки уходят;
  - `off` — картинки не проверяются.

  Не прошедший пост никуда не уходит: админам приходит картинка, причина и кнопки
  «✅ Всё равно переслать» (уйдёт во все таргеты) и «🗑 Убрать». Проверка занимает
  несколько секунд — Telegram-таргеты получают фото после неё.
- **Направления независимы**: у каждого (TG #1, Heaven, webhook Bee, каждый аккаунт,
  каждый selfbot-канал, Rebel Angels) своя очередь — посты в нём идут по порядку,
  а зависший аккаунт или упавший вебхук не задерживают остальных.
- **Discord selfbot и Rebel Angels**: первый канал — через `BRIDGE_DELAY_MIN..MAX` сек
  (10) от прихода поста, дальше паузы `SEND_DELAY_MIN..MAX` сек (5–7) между каналами.

## Переменные (новые и важные)
| переменная | по умолчанию | что это |
|---|---|---|
| `IMAGE_FILTER` | `strict` | проверка картинок: `strict` / `ads` / `off` |
| `BRIDGE_DELAY_MIN`, `BRIDGE_DELAY_MAX` | 10, 10 | сек от прихода поста до первого selfbot-канала |
| `SEND_DELAY_MIN`, `SEND_DELAY_MAX` | 5, 7 | сек между selfbot-каналами |
| `USER_SEND_TIMEOUT`, `USER_PHOTO_TIMEOUT` | 30, 90 | таймауты отправки от аккаунтов |
| `USER_START_DELAY` | 30 | сек до подключения аккаунтов после старта (защита сессий при деплое) |
| `OCR_THREADS` | 4 | потоков OCR |

## Сборка
Railway собирает по `Dockerfile` (python 3.11-slim + libgl1/libglib для OpenCV; модели OCR
распаковываются на сборке). Сессии аккаунтов: `python make_session.py` (локально, через
NekoBox; можно войти по QR — `qr` вместо номера) → `TG_USER_SESSION` / `TG_USER_SESSION_2`.
